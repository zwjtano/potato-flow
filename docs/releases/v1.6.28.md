# PotatoFlow v1.6.28

本次更新集中修复网页端在手机、平板和窄窗口下的自适应问题，并补充 Dota 2 主播人物别名。

## 修复

- 修复桌面侧栏折叠状态错误隐藏手机导航文字的问题。
- 修复手机访问会污染桌面侧栏折叠偏好的问题。
- 修复首次启动向导在 768–1179px 宽度下横向溢出的问题。
- 修复 YouTube 监控页移动端按钮过小、暗色主题卡片白底的问题。
- 修复人工审核页操作按钮在手机宽度下溢出的问题。
- 修复投稿中心危险操作区域在手机宽度下挤压的问题。

## 人物识别

- 补充一组人物别名和常见误写，并统一归一到已登记身份。
