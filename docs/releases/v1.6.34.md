# PotatoFlow v1.6.34

本版本改善 Windows 桌面版的 CPU、显卡与硬件编码器识别，重点修复 RTX 2060 可能被误判为 NVENC 不可用的问题。

## Windows 硬件识别

- 读取 CPU 型号与逻辑线程数。
- 枚举 NVIDIA、AMD 和 Intel 显卡，并显示型号与驱动版本。
- NVIDIA 额外通过 `nvidia-smi` 核对设备与驱动信息。
- 将硬件身份识别与 FFmpeg 编码实测分开显示，失败时给出明确原因。

## 编码器检测

- NVIDIA NVENC、Intel QSV 和 AMD AMF 使用兼容的 `640x360` 测试画面，避免小尺寸探测导致显卡误判。
- 自动模式优先选择实测可用的 NVIDIA、Intel 或 AMD 硬件编码器。
- 硬件编码失败时继续安全回退到 `libx264 / medium / CRF 20`。

## 界面

- 设置页和首次启动向导显示硬件型号、驱动、CPU 线程数、编码器可用状态与失败原因。
- 修复首次启动向导对编码能力列表解析不正确的问题。
