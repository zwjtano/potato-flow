# PotatoFlow v1.6.53

- Dota 2 封面中的每件确认装备现在要求在整张图中恰好出现一次；人物穿戴、手持、背负或腰挂已经计数，禁止再用悬浮图标、背景回声、镜像或倒影重复同一件。
- 生图前为每件装备建立唯一实体位置计划，明确穿戴、手持、背负、腰挂或身旁道具；已融入人物的装备不得再次沿边缘排列，人物的泛化护甲和武器也不得复刻其核心外形。
- 阿哈利姆神杖与俗称 A 杖视为同一件装备并固定为直接手持；同局的黑皇杖和克莱拉牧杖移到背部或侧后方，避免法杖重复或抢占手持位置。
- 生图前按装备 ID 读取 Valve 官方简体中文背景与功能说明，结合官方图标理解装备造型、材质、用途和自然穿戴方式；适合穿戴的优先融入人物，不适合穿戴的再作为身旁道具或能量焦点。
- 官方背景接口不可用时仍保留官方图标约束，不因补充资料下载失败阻断封面生成。
- 延续 v1.6.52 的百分比主播别名误判修复，以及 v1.6.51 的标题、简介、人物 Cos、全装备插画与提示词一致性优化。
