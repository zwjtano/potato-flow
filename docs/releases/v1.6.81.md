# PotatoFlow v1.6.81

- 修复 Telegram 命令菜单点击后无法先填写参数的问题。
- 点击 `/add`、`/record`、`/stop`、`/delete`、`/task`、`/retry`、`/pause` 或 `/delete_task` 后，机器人会提示输入，并把下一条文字作为命令参数。
- 引导输入两分钟内有效，可通过内联按钮取消；未授权会话仍无法创建或提交输入。
- `/start` 明确用于打开控制台，直播间开始录制统一使用 `/record`，避免 Telegram 默认启动命令产生歧义。
- Telegram 直播间页面新增完整设置入口：定时录制与起止时间、B站投稿账号、合集、分段开关与时长、录制画质、分P、仅录制、ASS 烧录，以及继承或自定义 ASS 参数。
