# PotatoFlow v1.6.58

## AI 封面流程优化

- 16:9 与 4:3 封面继续独立作图，同时复用主播、嘉宾头像及官方英雄、装备、技能参考素材，减少重复下载与处理。
- 封面视觉事实只使用第一核心事件，避免后续事件中的人物、英雄、技能或装备串入主画面。
- 提示词固定按“事实 → 身份 → 构图 → 文案 → 装饰”的顺序执行，后续装饰不得覆盖人物身份和事实边界。
- 自动投稿与人工重生成使用一致的封面文案规则。

## 弹幕烧录投稿标识

- 投稿视频成功烧录弹幕后，在投稿标题时间前加入“弹幕版”，例如 `标题｜弹幕版 08-07 02:05`。
- 未烧录弹幕的视频保持原标题不变。
- “弹幕版”仅用于投稿标题，生成或人工重生成封面时会自动剔除，不会出现在封面文字和视觉匹配上下文中。
