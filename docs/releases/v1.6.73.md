# PotatoFlow v1.6.73

## Windows 稳定性修复

- 修复关闭 Windows 桌面版时，底层 WebView 或子进程清理异常被误判为启动失败并弹出错误窗口的问题。
- 修复删除直播间并重载录制 worker 时，Windows 无效进程句柄导致页面显示 Internal Server Error 的问题。
- 正常退出期间的清理异常会记录到 `logs\desktop-shutdown.log`，不再打扰用户。
- 删除直播间遇到未预期错误时改为返回页面内的详细提示，不再显示默认 500 页面。
- 真正的启动失败仍保留错误提示和启动错误日志。

## Windows 发布

- 同步发布 Windows x64 安装版与便携版，并附带 SHA-256 校验文件。
