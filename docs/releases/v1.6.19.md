# PotatoFlow v1.6.19

## 仓库目录精简与 Docker 一键安装

- 将应用运行文件集中到 `potatoflow-app`，安装、服务和测试脚本集中到 `ops`，历史发布说明集中到 `docs/releases`，减少根目录散落文件。
- 清理内置录制核心中不参与生产构建的示例、Nix、Python 绑定和重复说明文件，保留 Rust workspace、数据库迁移、锁定文件与许可证。
- 新增 Linux Docker 一键安装脚本，默认使用国内 Docker、Debian、PyPI、PyTorch、Cargo 和 GitHub 下载源，并支持自定义 Web 端口。
- 保留旧应用目录、流水线配置和运行状态的兼容迁移；重复执行安装脚本不会清空现有配置、Cookie 或录播文件。
- 更新 README、Docker、systemd、CI 和测试入口，使其统一使用整理后的目录结构。
