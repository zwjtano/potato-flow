# v1.6.131

- 同步 biliup v1.2.8 的斗鱼网宿断流修复（上游 #1713、#1719）：保留原签名参数，追加 `expire=0`，避免受影响线路每 300 秒主动断开。
- 内置下载器遇到追加参数被 CDN 拒绝（HTTP 403）时，自动回退原直链，并明确记录原线路仍可能定时断流。
- FFmpeg 和 Streamlink 使用 HEAD 探测追加参数是否可用，避免 GET 探测消耗一次性拉流 token；Streamlink 每次重试使用最新解析的直链。
- 增加网宿识别、参数幂等、非网宿线路、HTTP 403 回退、HEAD 请求和 Streamlink 换源的回归测试及 Rust CI。

此修复需要更新并重新编译内置录制核心。Docker 用户需重新构建镜像；原生安装用户需重新编译 `recorder-core`；桌面用户需安装包含新核心的构建。仅更新 Python 文件或修改录制分段时长不会应用此修复。

上游参考：[biliup v1.2.8](https://github.com/biliup/biliup/releases/tag/v1.2.8)、[#1713](https://github.com/biliup/biliup/pull/1713)、[#1719](https://github.com/biliup/biliup/pull/1719)。
