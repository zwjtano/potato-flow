# PotatoFlow v1.6.64

## 底层流程与数据安全修复

- 配置文件改为进程内串行更新和原子替换，避免并发保存丢失字段或产生半写入 JSON；损坏配置会保留原文件，保存失败会明确返回错误。
- YouTube 自动加入投稿失败时不再提前标记为已入队，后续监控会自动重试。
- 同一 YouTube 监控配置只允许一次活动运行；历史数据升级时自动去重，并建立配置与视频唯一索引。
- 删除任务文件失败时保留数据库记录，避免产生无法从界面管理的孤立目录。
- 日志与下载目录清理增加服务端时长边界校验，逐项删除失败不再误报为全部成功。

## Windows 发布

- 桌面端打开期间持续阻止系统自动睡眠或休眠，确保录制与处理不中断；屏幕仍可按 Windows 电源设置自动关闭。
- 同步发布 Windows x64 安装版与便携版，并附带 SHA-256 校验文件。
