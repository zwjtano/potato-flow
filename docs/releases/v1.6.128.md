# v1.6.128

## LLM 调用效率

- 新增版本化 `PromptSpec` 注册表，为摘要、分类、翻译和字幕质检提供场景模型路由与输出 Token 上限。
- 新增私有 SQLite 结构化结果缓存；Prompt 版本、模型或完整语义输入变化时自动失效，人工重新生成显式旁路。
- 相同请求增加跨进程 single-flight，避免多个投稿进程同时击穿缓存并重复消耗 Token/RPM。
- 缓存读写前执行场景级结果合同校验，能解析但缺少必要字段的 JSON 不会被复用。
- 任务详情新增逻辑调用、真实请求、请求放大率、应用缓存命中、Prompt 缓存率、输入 Token 和成本。

## AI 字幕与免费 ASR

- 保持侧挂、持久化、内嵌和平台字幕优先；只有全部缺失时才调用 ASR。
- 新增 `free_pool`：Groq 免费 Whisper 额度/429 触发后自动切换 Cloudflare Workers AI。
- Groq 与 Cloudflare 使用各自独立 Key、模型与额度配置；不轮换同一 Provider 的多个 Key 绕过限制。
- 新增跨进程免费额度台账，按音频秒、小时/日窗口和 RPM 原子预留；台账不保存 Key。
- 全部免费 Provider 不可用时标记 `pending_free_quota`，禁止静默进入付费端点；部分窗口缺失时不输出伪完整字幕。

## Provider Control Plane

- 文本模型新增 4 个 Provider Profile：独立 Key、端点、模型、RPM 与场景，额度/容量/鉴权失败后跨进程熔断并自动切换。
- 图片模型新增 4 个 OpenAI-compatible Profile，生成和参考图编辑均支持备用 Key/端点切换；旧图片配置仍可作为可关闭的迁移回退。
- ASR 免费池通过统一能力、`free_only` 和优先级策略选择 Groq/Cloudflare；业务流程不再硬编码供应商判断顺序。
- 新增统一有效 Provider 注册表，覆盖 LLM、ASR、Image；尚未实现的 Gemini native/Tencent adapter 不会被伪装成可用。

## 内容证据与 OCR 流程

- TranscriptDocument 自动进入私有 SQLite/FTS5，保留原始/规范化文本并支持关键词和时间窗检索。
- 新增可选本地 OCR：FFmpeg 低频抽帧、dHash 去重、RapidOCR/ONNX Runtime、帧与模型版本缓存，不调用远端 Vision API。
- 任务详情新增“建立内容证据索引”和“提取 OCR 视觉证据”两个独立步骤，展示入库、去重、缓存命中、跳过原因和非阻断失败。

## 隐私与兼容

- 结果缓存只把输入哈希作为索引；本地结果可能包含生成译文，设置页提供明确披露与关闭模式。
- 继续支持原有 Whisper/OpenAI-compatible 与 Voxtral 配置；免费池为显式选择，不改变既有默认行为。
