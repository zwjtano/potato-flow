# PotatoFlow v1.5.29

- 重做斗鱼普通礼物统计：优先读取当前 v5 礼物目录，并用 v2 补齐特殊及兼容礼物，不再在采集阶段丢弃低价值或暂时无法定价的礼物。
- 普通礼物事件会保存礼物数量、连击、批量数量、道具标识、目录来源及定价诊断；简介输出阶段仍只展示单价不低于 100 元的付费礼物。
- 钻粉会员开通、续费和多月事件独立保存并按月份汇总；同一动作伴随出现的房间消息与广播消息会合并，不与“钻粉卡”等实际礼物混在一起，也不会在缺少成交金额时推算消费。
- 付费高能弹幕改用专用 `voice_trlt` 消息与官方展示队列双通道采集，按 `voiceRecordId` 去重，并使用 `realPrice / 100` 统计金额。
- 高能弹幕记录补充接收时间、悬停时长、来源和采集诊断，兼容 Socket 与队列数据互相补全。
- 官方记录缺少 `acptime` 时会明确标记为本地观察时间，不把抓取时刻伪装成官方接收时间。
- 同一 `voiceRecordId` 先由队列、后由 Socket 到达时，会合并来源并用 Socket 的官方 `acptime` 补正事件时间；金额保留到分，不截断小数元。
