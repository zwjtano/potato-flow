## 录播标题与任务时长

- 默认录播投稿标题不再追加“【直播回放】”，格式调整为“主播｜核心主题｜MM-dd HH:mm”。
- 已有的两种旧默认标题模板会自动迁移到新格式，自定义标题模板保持不变。
- 录播任务列表在封面缩略图右下角显示视频时长，格式为 `M:SS` 或 `H:MM:SS`。
- 视频时长仅作为任务 UI 浮层显示，不会写入、修改或上传到封面图片。
- 桌面表格和移动端任务卡片同步支持时长显示。
