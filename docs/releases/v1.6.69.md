# PotatoFlow v1.6.69

## 录播实际时长与重试修复

- 修复提前结束的录播仍被 FLV 容器标记为默认一小时时长的问题；任务展示、弹幕完整性检查和 AI 时间线统一使用实际录制墙钟时长。
- 修复重试时因错误的一小时时长拒绝复用已完成弹幕烧录视频、导致重复烧录的问题。

## 详细错误信息

- AI 弹幕批次失败时显示失败批次编号和上游实际错误，不再统一覆盖为 XML 时间点校验失败。
- 多批次错误会逐项汇总；HTTP 状态、限流、请求拦截、超时和网关错误均保留。
- Authorization、API Key、Token 和 Cookie 等敏感值在任务错误详情中自动脱敏。

## Windows 发布

- 同步发布 Windows x64 安装版与便携版，并附带 SHA-256 校验文件。
