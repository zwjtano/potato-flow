# PotatoFlow v1.6.80

- Telegram 远程控制升级为按钮式控制台，集中展示录制引擎、直播间、进行中任务、异常任务和磁盘状态。
- 新增直播间启停、任务详情、上传进度刷新、任务重试与暂停等内联按钮操作。
- 新增 AI 编辑工作台，可查看并重新生成标题、简介、标签以及 16:9、4:3 封面。
- AI 生成采用后台执行，Telegram 会及时响应按钮并在完成或失败后主动通知。
- 删除直播间、删除任务、停止录制引擎和 AI 重生成继续使用管理员白名单及限时二次确认。
- 保留原有 Telegram 文本命令，并新增 `/menu`、`/running`、`/errors` 和 `/ai`。
- README 顶部补充 Y2A-Auto 与 biliup 项目来源说明。
