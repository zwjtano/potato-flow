# v1.6.50

- Dota 2 封面不再只展示两件装备：有可靠 GSI 时完整保留当前事件对应的全部已确认装备，覆盖最多六格主装备以及单独确认的中立物品、神杖与魔晶状态，上限为八件。
- 装备允许像游戏切片封面一样自由融入构图：可集中或分散在画面边缘，也可作为手持、穿戴、身旁道具或技能能量焦点，并随透视调整大小、角度和光效；但不能漏掉确认装备、增加名单外装备或融合装备身份。
- Valve 官方图标表改为装备身份参考，不再把黑底商店图标和名称卡片直接压到最终封面；模型必须将全部确认装备转化为带描边、光效和层次的独立道具插画，标题直接点名的装备可以重点放大，其余装备沿上缘和两侧完整出现。
- Dota 2 封面优先采用不对称切片构图：主播与英雄一前一后作为主视觉，标题在另一侧或下方按语义排成两至三行，装备沿上缘和两侧错落分布；16:9 与 4:3 分别重排，避免装备遮脸、压字或在画幅边缘被裁断。
- 结构化 GSI 明确确认主播本人使用某英雄时，封面主视觉改为“主播 Cos 本局英雄”：保留人物底稿的脸部和卡通识别特征，换上英雄服饰、武器与技能光效，英雄本体可作为后方气势层；观战、讨论或仅由弹幕猜测英雄时禁止套用 Cos 关系。
- Dota 2 主播 Cos 统一采用高质量二次元 Q 版/游戏切片插画风格；即使直播间人物底稿来自真实头像，也只提取身份特征后卡通化，禁止生成照片皮肤、真人摄影或写实人像，修复真实头像被扩成真人风格封面的问题。
- 提高一小时录播标题的信息密度：证据充足时优先保留 30–46 字的主线、转折和结果，富时间线标题少于 24 字会要求模型重写；内容稀疏时仍允许自然短标题，不为凑字补猜。
- 封面大字与投稿标题继续分开生成，但证据充足时改为优先 16–24 字、最多 28 字，并保留人物或英雄、关键装备或阶段、动作、转折或结果中的多项有效信息，避免只剩一个泛化动作。
