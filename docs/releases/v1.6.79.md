# PotatoFlow v1.6.79

## TI 2026 比赛模式

- 新增 TI 2026 赛事识别、16 支队伍阵容、中文社区昵称、队徽和赛事赛制上下文。
- 新增中国时间与 Liquipedia UTC 时间窗口换算，减少跨日比赛错配。
- 新增 Liquipedia Match 页面与 OpenDota 赛后数据验证，可核对 Match ID、局次、胜负、英雄和选手 KDA。
- 接入 Valve `GetLiveLeagueGames` 实时联赛数据，读取 Match ID、比赛时长、当前击杀、英雄阵容、选手 KDA、经济和系列赛比分。
- 新增“比赛结束时间位于录像区间内”的精确归属及数据截取规则，排除赛后闲聊和下一场 BP。
- 新增整段录像无赛果时的“鏖战未决”标题与封面规则，实时击杀和 KDA 明确标注为录像截止数据。

## 设置与安全

- 系统设置新增 Steam Web API 密钥输入项。
- 密钥使用密码输入框，已配置时只显示占位标记，保存其他设置不会覆盖原密钥。
- 应用配置优先于 `STEAM_WEB_API_KEY` 环境变量，接口异常信息不会包含密钥。

- GitHub Release 自动构建并上传 Windows x64 安装包、便携包及 SHA-256 校验文件。
