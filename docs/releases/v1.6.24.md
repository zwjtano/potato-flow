# PotatoFlow v1.6.24

本版本将 v1.6.23 的封面人物一致性修复与全新的 Windows 桌面发行版合并发布。

## Windows 桌面版

- 同时提供 Program Files 安装版和真正便携版。
- 新增专业深色、自适应桌面控制台，支持导航自动折叠和高 DPI。
- 新增五步首次启动向导、运行组件自检和脱敏诊断页面。
- 安装版把录播与导出放在 `文档\PotatoFlow`，内部数据保存在 LocalAppData。
- `biliup.exe`、FFmpeg 与 ffprobe 随应用锁定，并写入 SHA-256 组件清单。
- Windows 进程使用 Job Object 管理，停止录制先优雅收尾，超时才强制结束。

## 录制与弹幕

- 修复 Windows 盘符被清洗为 `C_` 并误写临时目录的问题。
- 后处理支持结构化 `executable + args`，不再拼接 Windows shell 字符串。
- AMD/NVIDIA/Intel/CPU 使用通用尺寸探测，AMD 780M 推荐 `h264_amf / balanced / CQP 20`。
- 硬件编码失败时按任务回退 `libx264 / medium / CRF 20`，支持保留 2160p 源尺寸。
- 状态接口增加真实文件路径、大小、写入速度、最后更新时间和 worker 健康状态。

## 封面

- 包含 v1.6.23 的人物参考锁定与真人身份一致性改进。
