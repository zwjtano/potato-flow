# PotatoFlow v1.6.56

- 头像与英雄融合从“保持原脸、只换服装”升级为受控英雄化：在结构化数据确认主播亲自使用英雄时，自适应选取该英雄最有辨识度的视觉特征；范围不限于肤色、材质或少数器官，还可结合轮廓比例、体型姿态、服饰结构、元素效果与标志性能力特征，不套用固定清单。
- 英雄化后仍必须保留头像的帽子或标志头饰、发型、核心眼眉关系和原画风，确保一眼能认出原头像；禁止直接替换成英雄原脸、陌生人物或另一种真人/卡通类型。
- 真人底稿只允许通过妆效、假体、光影和非骨相皮肤特征表现英雄元素，不改变脸部骨相与五官关系；卡通或吉祥物头像可更明显地融合英雄形态。
- 最终人物表情跟随标题对应的已核验对局结果与关键局势变化；胜负不明确时保持专注自然，不根据零散弹幕猜测情绪。
- 刷新球、玲珑心、林肯法球、血精石等球形装备改为人物手掌上方或单侧肩旁悬浮，保持官方球体轮廓并与技能光球区分，不再硬嵌进身体或围绕人物排成一圈。
- 延续 v1.6.55 的完整人物合成方式：头像作为身份核心，英雄提供身体、服装、体态与技能氛围，本局装备按主手、副手、胸前、背部、腰间和双脚等计划装到同一人物上，不出现头像贴纸或第二个英雄。
