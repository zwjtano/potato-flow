# PotatoFlow v1.6.63

## DOTA2 人物与英雄识别热修复

- 修复 `DP`、`SF`、`PA`、`AM`、`TB` 等两字母常用英雄缩写被英文单词边界保护误挡的问题；缩写仍不会从 `DPS`、`template` 等普通单词中误命中。
- 补齐完整英雄名单中常见中文社区别名，包括剧毒、毒龙、黑贤、全能、小鹿、夜魔、双头龙、冰魂、毒狗、熊德、大树、尸王、小强、小精灵、海民、天怒、冰龙等。
- 支持“DP 才是谢彬玩的”“这 DP 奶哥玩得真肥”等英雄在人物前面的直接关系表达；“DP 击杀谢彬”“奶哥被 DP 追杀”等对手关系不会被误判成主播所用英雄。
- 修复同一句出现多个英雄时把后面的对手英雄错误绑定给主播的问题；重复出现但未绑定主播的对手英雄仍可保留为投稿标签，封面只使用已核验的主播英雄。
- 保持 v1.6.62 的保守共识门槛：仍需 15 分钟内至少两条不同原始 XML 弹幕直接绑定同一人物与英雄，单条弹幕、无人物归属刷屏和战斗对象关系均不能证明英雄归属。

## Windows 发布

- 同步发布 Windows x64 安装版与便携版，并附带 SHA-256 校验文件。
