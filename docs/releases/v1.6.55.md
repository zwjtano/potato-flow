# PotatoFlow v1.6.55

- Dota 2 装备位置计划新增左手副武器位：价格最高且适合持握的装备进入右手主武器，主武器之外价格最高且适合副手的长武器、法杖或短武器进入左手；两件必须保持完整独立，禁止融合、交叉遮没或画成同一把。
- A 杖继续遵守英雄属性限制：只有智力英雄才参与主手与副手选择；其他英雄固定背负。没有合适副武器时不强行占用左手，装备继续使用既定穿戴或背负位置。
- 细化一组已验证的六装备组合：假腿穿在双脚，冰眼成为胸前蓝白冰霜核心，大晕锤进入右手，金箍棒进入左手，蝴蝶形成背部绿色双翼，白银之锋从双翼中央斜向背负；六件仍各自只出现一次。
- 明确直播间头像与英雄、装备的融合方式：头像的脸、发型、帽子或标志头饰作为身份核心，英雄提供身体、服装、体态与技能氛围，本局装备再按逐件位置计划装到同一个完整 Cos 人物上。
- 禁止把直播间头像作为圆形贴纸或悬浮头像贴在封面上，也禁止“头像人物 + 英雄本体”双人并列；16:9 与 4:3 继续使用同一人物身份。
