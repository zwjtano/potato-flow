# PotatoFlow v1.6.57

## Dota 2 AI 封面布局

- 设置页新增“经典分离 / 英雄融合”切换，默认使用识别度更高的经典分离布局。
- 经典分离布局保留主播形象与官方英雄形象，并将官方装备图标独立放在画面外围；空间不足时可自动改用底部一排。
- 英雄融合布局保留新版的主播头像、英雄身体与装备融合效果，方便按直播间风格选择。
- 两种布局同时适用于 16:9 横版封面和 4:3 首页推荐封面，并继续使用已核验的官方英雄、装备参考图。

## 配置同步

- 布局设置保存后立即同步到封面生成配置，无需重启服务。
- 对旧配置保持兼容；未设置或配置值无效时使用经典分离布局。
