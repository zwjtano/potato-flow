# PotatoFlow v1.6.88

- 为 Apple Silicon Mac 增加 VideoToolbox H.264/HEVC 弹幕硬件编码，自动探测可用编码器并在失败时安全回退 CPU。
- 修正 VideoToolbox 画质映射、弹幕编码器设置读取和 Rosetta 下的 Apple Silicon 识别，统一速度、均衡与画质预设行为。
- 加固 ASS 字幕滤镜路径转义，支持中文、空格、引号、逗号、方括号和冒号等特殊字符路径。
- 全新 Mac 默认将录播保存到 `~/Movies/PotatoFlow/recordings`，将应用数据保存到 `~/Library/Application Support/PotatoFlow`，同时继续使用已有的非空旧录播目录，避免静默迁移或丢失数据。
- 将视频、弹幕 XML 与 `ASS_<视频名>.ass` 放在同一目录，并在上传后删除源文件时同步清理三者。
- 补充 macOS、Windows 和 Docker 跨平台回归测试，覆盖默认目录、字幕共置、清理流程与硬件编码边界。
