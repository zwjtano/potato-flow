# v1.6.44

- 修复 Windows 投稿时 `os.fchmod` 不可用导致的 Bilibili 上传异常，临时 Cookie 文件在支持该接口的平台上仍保持权限收紧。
- 弹幕烧录视频统一保存到原录播文件所在目录，并使用 `.danmaku.mp4` 后缀。
- 投稿失败后重试会先校验已有烧录视频；文件有效时直接复用，缺失或校验失败时才重新烧录。
- 每个录播文件的下载按钮后新增“打开所在文件夹”，Windows 会直接打开该文件对应目录。
- 仅由弹幕支持的签约、归属、官宣等现实状态不再直接写成事实标题，必须保留“弹幕称/观众讨论”等来源限定。
- 本版本恢复一次 Windows 构建发布，完成安装包、便携包及其 SHA-256 校验文件后，Windows 自动发布仍保持暂停。
