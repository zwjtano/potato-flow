# PotatoFlow v1.5.30

- 保留斗鱼 Dota 2 正常直玩局的主播视角英雄与最终装备识别，持续稳定的单英雄 GSI 数据仍作为第一优先级。
- 同一局内 `data.hero` 轮换多个英雄时，按观战或 OB 视角漂移处理，不再把最后一个视角英雄写成主播英雄。
- 只出现瞬时快照的稀疏 GSI 证据不再直接采信，避免录播边界局串入短暂出现的英雄。
- GSI 不可靠时，XML 仅在英雄提及量、领先倍数和总占比同时达到强证据标准时才作为兜底；证据不足时省略该局，不影响礼物和在线人数统计。
- 直播数据、主播英雄识别与 16:9/4:3 封面继续共用同一选择结果，任务流程会保存 GSI 持续时长以及 XML 第一、第二名分数与占比。
- 判定只依赖对局内英雄稳定性和英雄弹幕证据，不针对任何特定主播写特判。
