# PotatoFlow v1.6.62

## 录播投稿流程修复

- 已投稿任务改为使用持久化 BV 号判断发布状态；合集、评论或清理失败后仍可进入已投稿编辑器更新稿件。
- 加强人工介入与上传阶段之间的竞态保护；上传开始后不再错误暂停，重复暂停请求保持幂等。
- 人工审核已经补齐标题、简介和分区时，可直接绕过失败的 AI 元数据阶段继续投稿。
- 本地清理失败会保留为失败状态，重试时只处理明确记录的失败路径，不会重新上传视频。
- 简介评论拆分为独立投稿阶段；评论失败只重试评论，不重复上传视频或更新合集。
- GSI 缺失时可由原始 XML 中多条不同弹幕的直接人物英雄绑定形成保守共识；英雄识别已与 Valve 当前 127 个英雄完整名单对齐，并统一覆盖已登记人物别名，同时继续拦截单条传言、无人物归属的英雄刷屏和单字误匹配。
- 统一简介首轮、简介重试、标题重生成和封面提示词的证据优先级；XML 已核验的人物英雄关系可贯穿标题与封面，装备讨论不会被误写成最终物品栏，标题未出现主播时封面不再强塞主播称呼。

## 任务展示与重试

- 任务页面新增“发布简介评论”阶段及独立状态说明。
- 已有 BV 号但后置步骤失败的任务会正确显示为已投稿任务，并保留编辑、同步和安全重试能力。

## Windows 发布

- 同步发布 Windows x64 安装版与便携版，并附带 SHA-256 校验文件。
