# PotatoFlow v1.6.25

Windows 桌面启动与卸载热修复。

## 修复

- 桌面服务不再固定使用 5001，启动时选择可用的本地端口。
- 启动握手同时验证桌面令牌和随机实例标识，避免误连旧版 PotatoFlow 服务并显示 404。
- 安装升级通过单实例互斥量要求旧版先退出。
- 卸载前停止 PotatoFlow 主进程和服务进程，释放 `_internal` 中被占用的 DLL。
- 卸载时清理安装目录内的残余运行组件。
- 用户文件清理仅覆盖 `文档\PotatoFlow\recordings` 和 `exports`，不再删除整个 `文档\PotatoFlow`。
- 检测到 `.git` 或 PotatoFlow 源码结构时拒绝执行用户文件清理。

## 验证

- 在旧服务持续占用 5001 的情况下，新 EXE 自动使用其他端口。
- 打包后的 `/healthz` 返回 1.6.25 和当前实例标识。
- 首次启动 `/onboarding` 返回 HTTP 200。
- Windows 桌面启动及卸载保护回归测试通过。
