# PotatoFlow v1.6.54

- 修复 Windows 删除直播间时因配置文件被录制进程短暂占用而直接显示 `Internal Server Error` 的问题：原子替换会对共享冲突进行短暂重试，删除和录制 worker 重载失败时改为返回可理解的页面提示，并明确不会删除已有录播文件和上传任务。
- 修复任务详情中“烧录弹幕字幕”实时进度在暗色模式下仍显示浅色卡片的问题，补齐暗色背景、边框、文字和进度条配色。
- 默认直接使用直播间头像作为封面人物底稿；用户上传或内置固定底稿仍具有更高优先级。16:9 与 4:3 封面统一锁定同一人物底稿，允许调整表情、动作、服装与背景，但不再强制动漫化、Q 版化或重画另一张脸。
- Dota 2 封面禁止把装备沿人物外围排成环形、放射状、花环式、左右对称或物品栏式图标圈；优先将装备自然穿戴、手持、背负或腰挂，剩余道具只在一处次要场景区域形成不对称层次。
- 所有已确认装备仍须逐件出现且不得重复；美观与识别度同等重要，通过透视、材质光影、前后景和人物动作自然融合，禁止为露全装备而退化成生硬的大图标或贴纸。官方价格达到 2500 金币的高级装备统一提高轮廓、主色、材质与标志性符号的可辨识度，不再为巫师之刃设置独立外观特例。
- Valve 官方小尺寸装备图标在参考板中使用整数倍无插值放大，仅用于锁定装备身份；成图要求二创为边缘清楚、材质明确的高清实体装备，同时保持官方轮廓、配色、构件关系和核心符号。
