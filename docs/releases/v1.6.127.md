# v1.6.127

## AI 调用治理

- 新增统一 LLM 编排层：稳定 Prompt Cache key/TTL、官方端点能力策略、跨进程滑动窗口 RPM、Retry-After 与指数退避。
- 关闭 OpenAI SDK 隐式重试；每次真实物理请求、降级和重试均独立计数并写入隐私化账本。
- AI 账本新增 `job_id`、`job_purpose`、缓存写入 token 和对应成本，区分元数据、字幕、标签分区及双封面作业。
- 房间级提示词与本次时间范围从 system 前缀迁移到变量 payload，提升缓存前缀稳定性。
- 字幕翻译、字幕质检和 AI 智能分段复用统一连接池、缓存、RPM 与重试治理。

## 录播流程

- 新增独立“处理 AI 字幕”阶段：按侧挂字幕、持久化字幕、内嵌字幕、平台字幕、ASR 兜底的顺序渐进处理。
- 支持复用 `*_AI字幕.srt` / `*.ai.srt` 命名；已有字幕不重复调用 ASR。
- ASR 生成字幕可执行质检；质检失败保留字幕产物，但不会污染 AI 元数据证据或阻断投稿。
- B站合集接口返回 `20080`（稿件已存在）时按幂等成功跳过，不再令投稿失败或触发无效重试。

## 精简与稳定性

- 删除过期的 TI 2026 专用赛事模式、Liquipedia/OpenDota 核验、赛事封面模块、预取脚本、测试和静态资源；保留通用 DOTA2/GSI 能力。
- Windows 子进程统一使用 UTF-8 解码，并增加静态契约测试，避免系统代码页导致路径和错误信息损坏。
- 测试脚本自动选择仓库 Python 3.11 环境并强制 UTF-8；Windows 无符号链接权限时安全跳过对应测试。
