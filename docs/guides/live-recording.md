# 直播录制

直播录制页负责直播间、录制引擎和当前生成文件；已结束的任务统一进入“上传任务”。

## 添加直播间

1. 点击 **新增直播间**。
2. 粘贴完整房间链接。
3. 等待系统识别平台、主播名、头像、标题和真实房间号。
4. 检查识别结果后保存。

支持：

```text
https://live.bilibili.com/123456
https://www.douyu.com/9999
https://live.douyin.com/123456
```

斗鱼靓号会解析成平台真实房间号，但界面仍保留你熟悉的直播间入口。

## 手动开始与停止

- 录制引擎开启后会持续检测房间。
- 单个直播间可随时手动开始录制。
- 手动停止会先安全收尾当前视频与 XML，再把该文件送入 ASS、AI 和投稿流程。
- “仅录制不投稿”开启时，不创建上传任务；收尾后生成同名 ASS 与 AI JPG 封面。若同时开启 ASS 烧录，先排队烧录，再把烧录结果封装为带内嵌封面的 MP4；否则直接封装原视频。任一步失败都会保留原 FLV。

## 单直播间设置

  <img src="../../assets/screenshots/local-recording-settings-v1619.webp" alt="虚构直播间的录制分段与投稿方式设置面板">
  <figcaption>展开“录制分段与投稿方式”即可单独配置当前直播间；示例直播间为虚构。</figcaption>
</figure>

每个直播间可独立设置：

- 是否分段（默认开启）
- 录制分辨率（原画、最高 2160p、最高 1080p 或最高 720p）
- 分段时长（默认 60 分钟，范围 1–1440）
- 是否合并为分P（默认关闭）
- 是否仅录制不投稿（默认关闭）
- 是否把 ASS 弹幕烧录进视频（默认关闭）

分辨率是平台画质档位的统一表达：B站、斗鱼和抖音会分别转换为对应的画质参数。若主播当前没有提供指定档位，录制引擎会自动选择最接近的可用画质。录制中修改分辨率会先安全收尾当前分段，再应用新设置。

## 投稿中心与换源

“任务中心 → 投稿中心”按已配置的 B站账号同步历史稿件，可按状态分页查看、筛选当前页或直接输入 BVID 定位。选中稿件后，可查看分P和 CID，编辑标题、简介、标签与分区，也可查看近期评论并手动回复。所有回复都要求在明确的评论对象下二次确认，系统不会自动发言。

投稿中心也可以把服务器上已完成 ASS 烧录的视频替换到指定分P。普通稿件信息编辑不改动封面、视频源或分P；换源始终使用独立的高风险确认流程。

换源前必须再次完整输入 BVID。系统会重新读取远端分P，只替换目标分P的视频源，保留其他分P和稿件元数据，再进入全局 B站上传队列。换源会重新提交 B站审核，请在队列中确认最终状态。
