# 分段与分P

“录制分段”和“合并为分P”是两件独立的事。

| 设置 | 默认值 | 效果 |
|---|---:|---|
| 开启录制分段 | 开启 | 每到设定时长安全结束文件，并立即处理 |
| 分段时长 | 60 分钟 | 每个直播间可设 1–1440 分钟 |
| 合并为分P | 关闭 | 每个完成文件独立投稿 |
| 仅录制不投稿 | 关闭 | 开启后不创建投稿任务 |

## 独立投稿（默认）

每个录制分段完成后立即生成 ASS、AI 稿件和封面，然后独立投稿。后面的分段不必等待整场直播结束。

## 合并为分P

开启后：

1. P1 创建 B站稿件并取得 BVID。
2. 后续分段完成后追加到同一 BVID。
3. 每一 P 根据本段弹幕生成独立页面标题和摘要。
4. 稿件简介汇总全部已完成分段。

分P标题采用“几点 + 本段主题”，不再只显示 `P1`、`P2`。

## 不分段

关闭分段后，整场直播只写一个视频和一份 XML。直播自然结束或手动停止时，文件安全收尾后才进入后续流程。

!!! note
    不分段时无法“每小时自动投稿”，因为在直播结束前没有完整、可投稿的成品文件。
