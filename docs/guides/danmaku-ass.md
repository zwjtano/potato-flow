# 弹幕与 ASS

PotatoFlow 在录制视频的同时保存 XML 弹幕。每个视频分段完成后，会把对应 XML 转换为 ASS 字幕文件。

```mermaid
flowchart LR
    A[直播视频分段] --> C[同名视频文件]
    B[实时弹幕] --> D[同名 XML]
    D --> E[生成 ASS]
    E --> H{该直播间开启烧录?}
    C --> H
    H -->|是| I[排队烧录 ASS]
    H -->|否| F[使用原视频]
    I --> J[上传或仅录制保留]
    F --> J
    E --> G[保留/下载字幕]
```

## 为什么不默认烧录

烧录需要重新编码整段视频，消耗大量 CPU、时间和磁盘临时空间。PotatoFlow 默认上传原画视频，并把 ASS 作为独立产物保存，避免不必要的转码。

需要时，在“直播录制 → 直播间设置”开启 **烧录 ASS 弹幕进视频**。该开关同时作用于正常投稿和“仅录制不投稿”：两种流程都会保留独立 ASS，并使用烧录后的视频继续处理。

## 烧录队列

多个分段同时收尾时，烧录任务会按先后顺序串行执行，任务步骤会分别显示“等待烧录”和“正在烧录”。该队列同时覆盖单进程多线程和多进程容器内的任务，避免多个 FFmpeg 烧录抢占资源。

## 如何检查

在“上传任务”点击处理进度，打开 **生成 ASS** 步骤，可以查看：

- XML 路径
- ASS 路径
- 识别到的弹幕数量
- 是否启用烧录
- 原始执行日志

!!! tip
    视频、XML 和 ASS 使用同一分段时间关系。下载 ASS 后，可在支持外挂字幕的播放器中直接加载。
