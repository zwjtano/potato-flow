## 1. 登录 B站

进入 **系统设置 → 账号与网络 → 平台账号**：

- B站可扫码登录，也可以上传 Cookie 文件。
- 登录后使用页面上的登录态校验确认可投稿。
- 遇到 SSL 证书错误时，先更新 Linux 的 CA 证书，不要关闭 TLS 校验。

## 2. 配置 AI

进入 **系统设置 → AI 与自动化**，填写兼容 OpenAI API 的：

- API Key
- Base URL
- 文本模型
- 图像模型（默认用于 AI 封面）

未配置 AI 或 AI 请求失败时，任务会保留可人工编辑的内容，不会静默丢失。

## 3. 开启自动化

在常用流程中按需要启用自动投稿、自动生成标签、自动推荐分区和 AI 封面。直播录播投稿使用“自制”类型。

## 4. 添加直播间

进入 **直播录制 → 新增直播间**，粘贴哔哩哔哩、斗鱼或抖音直播间地址。系统会解析真实房间号、主播昵称、头像和直播标题，确认后再保存。

!!! info "平台边界"
    抖音只用于直播检测、录制和弹幕采集；投稿仍只发送到哔哩哔哩。
