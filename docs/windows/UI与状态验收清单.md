# Windows UI 与状态验收清单

## 窗口与输入

- [ ] 1440×900：导航 224px，主内容无横向溢出
- [ ] 1180×720：导航折叠为 72px，多栏内容改为单栏并可滚动
- [ ] 125%、150%、175%、200% DPI：文字不截断，主要按钮始终可见
- [ ] Tab 顺序合理，焦点框清晰，Enter/Space 可操作按钮
- [ ] 长中文标题、长路径与详细错误文本可换行

## 页面

- [ ] 五步首次启动向导可完成，也可跳过全部可选服务
- [ ] 总览突出正在录制、待审核、失败任务与磁盘空间
- [ ] 直播间工作台正确显示真实文件路径、大小、写入速度和 XML 状态
- [ ] 任务中心阶段为：录制 → XML → ASS → 烧录 → AI → 封面 → 审核 → 投稿
- [ ] 审核工作台并排显示 16:9 / 4:3 封面及人物参考来源
- [ ] 文件库按主播、场次、分段聚合全部产物
- [ ] 设置各组显示已配置、缺少配置或检测失败
- [ ] 诊断页显示组件路径与 SHA-256，且不泄漏敏感配置

## 状态与系统集成

- [ ] 空、加载、失败、告警、磁盘不足与组件缺失状态均有原因和建议动作
- [ ] 托盘可打开窗口、查看录制数、打开录播目录和退出
- [ ] 关闭窗口仅隐藏到托盘；退出时若正在录制必须明确确认
- [ ] 系统通知对同类高频事件合并
- [ ] 安装版仅监听 `127.0.0.1`
- [ ] 安装版与便携版数据互不污染
