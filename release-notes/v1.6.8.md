# PotatoFlow v1.6.8

## 主播英雄识别修复

- 所有直播间统一以斗鱼 GSI 明确的主播视角英雄为主，不依赖固定阵容位置。
- 当 GSI 未能给出完整十人阵容时，仍保留持续稳定的顶层 `hero` 数据，用于英雄和最终装备。
- 完整阵容内验证过的 GSI 证据优先级最高；GSI 不稳定或中途切换英雄时不强猜。
- XML 弹幕仅作为旧数据的保守兼容兜底，改为统计独立弹幕条数，单条复制刷屏不再误判英雄。
- AI 生成的标题、简介和时间点不再反向提升为英雄身份证据，避免把观众讨论的其他英雄画到封面。
- 正常生图和重新生图共用同一套 GSI 优先身份判定。

## 国内构建源

- Docker 构建新增可配置的 Debian、PyPI、PyTorch、Cargo 和 Deno 下载源参数；Cargo 使用官方支持的 source replacement 机制，默认构建不写入任何镜像配置。
