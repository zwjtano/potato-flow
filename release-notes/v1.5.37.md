# PotatoFlow v1.5.37

- 每个直播间可独立选择原画、2160p、1080p 或 720p，并按 B站、斗鱼、抖音的画质参数分别下发给 biliup。
- 未配置封面人物底稿时，自动使用当前录播精确匹配到的直播间头像；专用底稿和自定义底稿仍优先。
- 完善投稿中心：新增稿件详情、分P/CID、当前页筛选、打开稿件和复制 BV 号。
- 支持在投稿中心编辑历史稿件的标题、简介、标签和分区，不改动封面、视频源或分P。
- 投稿中心可查看近期 B站评论并对指定评论手动回复；发布前必须明确确认，不会自动回复。
- 新增 B站消息概览，按投稿账号展示评论/回复、私信、收到的赞和系统通知的未读数与最新预览，并可跳转 B站官方消息中心处理。
- 修正任务详情的阶段排序，烧录弹幕现在会按真实执行顺序显示在封面生成与 MP4 封装之前。
- 烧录阶段实时显示完成百分比、转码倍率和预计剩余时间，适合跟踪 2160p 长视频。
