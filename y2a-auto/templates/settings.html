远程控制

在 Telegram 内管理直播间、处理失败投稿、查看实时上传进度与录播文件，并控制录制引擎。默认关闭。

必须填写 Telegram 数字 User ID。命令还必须来自上方配置的 Chat ID；群组内也只允许白名单用户操作。
直播间管理： /rooms 查看列表， /add <直播间链接> 添加， /delete <编号/名称> 删除。
录制控制： /start 或 /record <编号/名称> 开始， /stop <编号/名称> 停止；支持列表编号、完整房间号或唯一名称。
任务处理： /tasks 最近任务， /task <编号/ID> 详情与上传速度， /retry <编号/ID> 重试， /pause <编号/ID> 暂停， /delete_task <编号/ID> 删除记录并保留文件。
服务与文件： /files 最近文件， /engine 引擎状态， /engine start 启动， /engine stop 安全停止， /status 服务状态， /disk 磁盘空间， /help 命令帮助。
安全保护： 命令必须同时匹配 Chat ID 和管理员 User ID 白名单；删除直播间、删除任务记录和停止整个录制引擎均须在 2 分钟内二次确认。任务重试会复用已有 AI 简介与封面。
